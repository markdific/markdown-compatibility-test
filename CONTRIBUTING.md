# Contributing to the Markdown Compatibility Test Pack

Suggestions and reproducible test cases are welcome once the repository owner enables GitHub issues and pull requests.

## Propose a test case

Include:

1. The Markdown source as a minimal example.
2. The syntax family: CommonMark, GFM, another extension, or application-specific syntax.
3. The behaviour you expect and a link to the relevant specification or product documentation where possible.
4. Why this case matters in a real document or conversion workflow.
5. Any images or other fixtures, with their origin and permission to release them under CC BY 4.0.

Do not silently change an existing versioned test file. A clarification can use a patch version; added sections need a new version and a brief change note. Preserve old versions so published comparisons remain reproducible.

Contributed test text and fixtures intended for inclusion must be material you have the right to provide under [CC BY 4.0](LICENSE.md). Do not include private documents, credentials, third-party logos, or copyrighted images without appropriate permission.

The pack is independent of any app's product score. Please report observed results with application version, operating system, configuration, and export settings. A tool's lack of an optional extension is not automatically a defect.
